# Dashboard screenshots

Save the final screenshots in this folder using these exact filenames:

1. `dashboard-overview.png` — capture the dashboard from the title through the NRC emotion distribution, including the headline metrics, distributions, confusion matrix, class accuracy, and neutral-review outcomes.
2. `dashboard-review-table.png` — capture the review-table heading, filter controls, visible-row count, column headers, and several representative rows.

Recommended capture width: 1400–1600 pixels. Use PNG format, keep browser zoom at 100%, and avoid including browser tabs, the address bar, or unrelated desktop content. The root README already references these filenames, so replacing them with the screenshots will make the images appear automatically.
